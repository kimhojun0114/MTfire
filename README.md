# 🔥 대한민국 산불 20년 — 분석과 탐색

산림청 산불통계(2006~2025년, 총 9,240건)를 월별·원인별로 분석하고, 사용자가 직접 축을 골라 2D·3D 그래프를 만들어 볼 수 있는 인터랙티브 시각화 사이트입니다.

인공지능 융합 프로젝트(드론 기반 산불 감지)의 기초 데이터 분석으로 제작했습니다.

## 사이트 보기

`index.html`을 브라우저로 열면 됩니다. 그래프 라이브러리(Chart.js, Plotly)를 인터넷에서 불러오므로 온라인 상태여야 합니다.

GitHub Pages를 켜면 웹 주소로 공유할 수 있습니다: 저장소 **Settings → Pages → Branch: `main` / `(root)` → Save**

사이트는 두 화면으로 구성됩니다.

- **분석 이야기**: 월별·연도별 발생, 원인별 변화, 특이 연도 분석, 기후·인위 요인 정리
- **직접 탐색**: 연도·월·원인 중 축을 골라 그래프를 만드는 탐색기 (2D/3D, 합계·평균, 비율·로그 눈금, 설정 링크 공유)

## 주요 결과

- 2~4월에 전체 산불의 **61.1%** 가 발생하고, 3월(25.2%)이 가장 많습니다.
- 원인마다 몰리는 달이 다릅니다. 논밭두렁·쓰레기 소각은 3월, 입산자 실화는 4월, 성묘객 실화는 4월과 9월에 많습니다.
- 기상가뭄이 100일 이상이었던 해는 산불이 평균 약 **1.6배** 많았습니다(상관계수 r = 0.61).
- 가뭄 일수와 **피해면적**의 관계는 약합니다(r = 0.25). 대형 피해는 불이 난 며칠간의 강풍·고온·극건조에 좌우됩니다(예: 2025년 3월 21~26일).
- 건축물 화재에서 번진 산불은 전기(2006~15) 연평균 9.0건에서 후기(2016~25) 36.8건으로 약 4배가 됐습니다.

## 폴더 구조

```
index.html                 사이트 (분석 이야기 + 직접 탐색)
data/
  raw_kosis_monthly_cause.xlsx   KOSIS 원자료
  fire_long.csv                  정리한 데이터 (월, 연도, 원인, 건수)
  cube.json                      사이트용 [연도][월][원인] 배열
analysis/
  01_prepare_data.py             원자료 → fire_long.csv, cube.json
  02_make_figures.py             분석 그래프 PNG 6종
  03_make_3d_figures.py          3D 그래프 PNG 2종
figures/                   보고서용 그래프 이미지
prototypes/                초기 시안 (3D 탐색, 산불 달력 인포그래픽)
```

분석을 다시 실행하려면 저장소 최상위 폴더에서:

```bash
pip install pandas openpyxl matplotlib
python analysis/01_prepare_data.py
python analysis/02_make_figures.py
python analysis/03_make_3d_figures.py
```

그래프에 한글 글꼴(Noto Sans CJK)이 필요합니다. 다른 글꼴을 쓰려면 스크립트 위쪽의 `FONT` 경로를 바꿔 주세요.

## 데이터 처리 원칙

- 원본의 `-`는 0건으로 처리했습니다.
- 2022년에는 원자료에 `어린이불장난` 항목이 없습니다. 0이 아닌 **결측**으로 보고, 합계에서는 빠지며 평균에서는 분모에서 제외합니다.
- 2025년 기상가뭄 일수는 같은 방식의 공개 자료가 없어 결측으로 두었습니다.
- 기상·사회 자료로 설명되지 않는 값(2007년 2월, 2010년 11~12월 등)은 임의로 해석하지 않고 **이상치**로 남겨 두었습니다.
- `기타`는 '원인 미상'만이 아니라 8개 분류에 들지 않는 방화·산업시설·군사훈련·원인미상 등을 합친 값입니다.
- 이 자료는 발생 **건수**이며 피해면적과는 다른 지표입니다.
